# 学習用の掲示板アプリ

Laravel (PHP) と Vue.js を使用して作成する学習用の掲示板アプリです。

## 概要

本プロジェクトでは、Laravel をバックエンド、Vue.js をフロントエンドとして利用し、掲示板アプリケーションを開発します。

Laravel の基本機能であるルーティング、コントローラー、モデル、マイグレーションに加え、Vue.js を用いたフロントエンド開発や API 通信について学ぶことを目的としています。

## 主な機能

- ユーザー登録・ログイン
- 投稿の作成
- 投稿一覧の表示
- 投稿の編集・削除
- コメント機能
- バリデーション
- ページネーション

## 使用技術

### バックエンド

- PHP
- Laravel
- SQLite

### フロントエンド

- Vue.js
- JavaScript
- HTML / CSS

### 開発環境

- Git
- GitHub
- Visual Studio Code

## 学習目標

- Laravel の基本的な MVC アーキテクチャを理解する
- REST API の実装方法を学ぶ
- Vue.js による画面開発を習得する
- Git / GitHub を利用したバージョン管理を学ぶ
- フルスタックな Web アプリケーション開発の流れを理解する
